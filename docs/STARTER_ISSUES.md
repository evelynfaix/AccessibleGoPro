# Starter issues

This file is the initial backlog for contributors and collaborators.

## High priority

### 1. Camera connection
- Confirm the best supported connection method using OpenGoPro
- Decide whether Wi‑Fi, BLE, or both are needed for the first version
- Document the camera connection flow

### 2. Spoken status updates
- Read battery, mode, recording state, and system errors aloud
- Decide when automatic spoken updates are appropriate
- Make sure status is clear, short, and understandable

### 3. Recording control
- Create a VoiceOver-friendly recording start/stop flow
- Clearly announce when recording begins and ends
- Support recording without visual inspection

### 4. Settings browsing and editing
- Build a hierarchical settings menu
- Support spoken readout of current settings
- Make changes easy to understand and confirm

### 5. Confirmation feedback
- Speak and/or vibrate after important actions
- Announce settings changes clearly
- Make error recovery easy to understand

## Medium priority

### 6. Settings prioritization
- Decide which settings are essential for the first demo
- Rank settings by user impact and ease of implementation
- Keep the initial settings menu manageable

### 7. VoiceOver labels and hints
- Ensure all buttons and actions have meaningful labels
- Add hints for complex settings and actions
- Check the app for focus and navigation issues

### 8. Blind-user testing workflow
- Create a test script for real users
- Document usability problems and improvements
- Gather direct feedback from blind users

## Future ideas

### 9. Presets and custom workflows
- Add a preset feature for common recording scenarios
- Support quick mode changes like "Night", "Action", or "Timelapse"

### 10. Voice command support
- Explore simple spoken commands for key actions
- Evaluate future integrations with Siri or custom command layers

### 11. Multi-platform exploration
- Consider whether Android or desktop tools could supplement the iPhone app

## Notes

These issues are intentionally simple but important. They give contributors a way to help early, even before the full product architecture is complete.
