# Project overview

AccessibleGoPro is an accessibility-focused iPhone app project for blind and low-vision GoPro users.

## Mission

Make GoPro cameras usable without requiring a sighted person to read the camera screen or navigate visual-only controls.

## Core goals

- connect to a GoPro from an iPhone
- read camera state aloud with VoiceOver
- start and stop video recording clearly and reliably
- expose important and advanced settings in a spoken interface
- confirm every state change and action with clear feedback
- support blind users in everyday GoPro use cases

## Product vision

The app should feel like a spoken camera control panel. Instead of asking users to look at a screen, the interface should say what is happening, what settings are current, and what actions are available.

## MVP

The initial release focuses on:

- connection to a GoPro
- spoken battery and mode status
- recording start and stop
- list and change of key settings
- clear audio and haptic confirmation

## Future directions

- broader settings coverage
- preset workflows
- advanced voice command support
- testing with blind and low-vision participants
- Android or cross-platform exploration

## Relationship to OpenGoPro

This project builds on the OpenGoPro protocol and developer resources. OpenGoPro provides the technical foundation for camera communication; AccessibleGoPro provides the accessible user experience layer.
